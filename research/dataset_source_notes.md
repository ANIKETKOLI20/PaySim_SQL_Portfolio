## Dataset Description

PaySim is a synthetic mobile-money transaction dataset
generated using a financial transaction simulator.

It represents simulated mobile-money activity
across five transaction categories.

## Known Limitations

1. Synthetic rather than actual production transactions.
2. Limited calendar information.
3. Primarily a single transaction table.
4. No separate customer master table.
