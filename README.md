
# PaySim SQL Portfolio

## Project Overview

This project demonstrates practical SQL skills using the
PaySim synthetic mobile-money transaction dataset.

The primary objective is to develop hands-on experience in
querying financial transaction data, performing aggregations,
analysing transaction patterns, and validating analytical results.

## Dataset

**Dataset:** Synthetic Financial Datasets For Fraud Detection

**Source:** Kaggle  
https://www.kaggle.com/datasets/ealaxi/paysim1

**Original Research Paper:**  
PaySim: A Financial Mobile Money Simulator for Fraud Detection (2016).

**Licence:** CC BY-SA 4.0  
https://creativecommons.org/licenses/by-sa/4.0/

The original CSV is not included in this repository.
Please obtain it from the original dataset source.

## Important Note

PaySim contains synthetic financial transactions.
Findings from this dataset should not be interpreted
as actual production payment-platform behaviour.

Lopez-Rojas, E.A., Elmir, A., and Axelsson, S. (2016).
